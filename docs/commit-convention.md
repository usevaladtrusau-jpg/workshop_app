# Commit Convention 
    Use in commit messages prefix(fix, feat, docs, refactor). Ref: https://www.conventionalcommits.org/en/v1.0.0/
    Example of commit message: "fix: update authorization scopes";
    "feat: add cron-job for updating order stutuses"
    "docs: add documentation for new endpoints" -- regarding to .docs, .doc, .md files
    "refactor: replace files from ... to ...", "refactor: rename file, class ..."
